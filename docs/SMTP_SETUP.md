# Настройка SMTP

Заявки из всех форм отправляются напрямую на почту через SMTP. В формах передаются только ФИО, телефон, согласие и технический honeypot. В заказе дополнительно передаётся состав корзины.

1. Скопируйте `.env.example` в `.env`.
2. Укажите пароль приложения в `NUXT_SMTP_PASS`. Не используйте обычный пароль от почты.
3. При необходимости измените SMTP-сервер, отправителя и адрес получателя.
4. Перезапустите сервер после изменения переменных.

Для Яндекс Почты используются `smtp.yandex.ru`, порт `465` и защищённое соединение. Файл `.env` исключён из Git.
